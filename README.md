# Baby shower de Marcelo

Abre `index.html` para ver la invitación. El diseño, la ilustración y la música están incluidos en la carpeta.

## Publicar con GitHub y Vercel

1. Crea un repositorio en GitHub y sube el contenido de esta carpeta. Comprueba que `index.html` y `assets/` estén en la raíz.
2. En Vercel, crea un proyecto e importa ese repositorio.
3. Selecciona **Other**, conserva la raíz del repositorio y deja el comando de compilación vacío. Pulsa **Deploy**.
4. Abre la dirección que te entregue Vercel y compártela con tus invitados.

## Cambios

Edita el texto y el enlace de Google Maps en `index.html`. La grabación está en `assets/musica.wav` y se repite durante la visita. Si el navegador bloquea el inicio automático, toca **Activar música**. El mismo botón permite pausarla.
